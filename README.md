# Land Price Prediction

Predicts the price of a plot of land from its size (in square feet) using Linear Regression.

## Tools
Python, pandas, NumPy, matplotlib, scikit-learn

## What I did
- Loaded a small dataset of 10 plots with land size and price
- Visualised the relationship between land size and price
- Trained a Linear Regression model
- Predicted the price for a new plot size and drew the fitted line
- Verified the prediction manually using y = m*x + b

## Files
- `03_land_price_prediction.ipynb`: the full notebook

## Dataset
A small dataset of 10 plots with land size and price. The dataset file is not included in this repository.

## How to run
Install the libraries:

    pip install pandas numpy matplotlib scikit-learn

Then open the notebook in Jupyter and run all cells.
